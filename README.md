# личный сайт стримера

На сайте 6 разделов:
1. Страница с информацией о стримере
2. Страница со ссылками на соцсети стримера
3. Страница посвящённая просмотренным на стримах фильмам
4. Страница посвящённая донатной рулетке
5. Страница с расписанием стримов
6. Страница со всеми апдейтами сайта

# техническая информация
1. Вместе с сайтом в связке работали несколько ботов (telegram-бот, twitch-бот, donationalerts-бот), но для архивного размещения сайта в публичном репозитории весь лишний api был убран, чтобы проект был отдельный.
2. В силу ограничений на ресурсы сервера (512 Мб оперативной памяти) использовалась СУБД SQLite. Так же использовался файл подкачки на 1 Гб.
3. Сайт размещался на сервере Ubuntu 24.04 LTS "Noble Numbat" [x64] в связке с NGINX, с настроенным логированием, ротацией логов (утилита logrotate), мониторингом работоспособности сайта и ботов через скрипт по расписанию и оповещениями в telegram бота.
